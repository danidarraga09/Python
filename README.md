# Python
Crea un grafo con 4 nodos y 6 aristas (todos conectados con todos)
Verifica si es conexo — si se puede llegar de cualquier nodo a cualquier otro
Encuentra las componentes conexas — grupos de nodos conectados entre sí
Calcula el diámetro — la distancia más larga entre dos nodos cualquiera
Calcula el radio — la distancia más corta desde el nodo más "céntrico"
Encuentra el centro — los nodos con menor excentricidad
Verifica si es euleriano — si existe un circuito que recorra todas las aristas una sola vez
Aplica Fleury — intenta construir ese circuito euleriano de forma cautelosa
Aplica Hierholzer — intenta construir ese circuito euleriano de forma eficiente
Busca un ciclo hamiltoniano — un camino que pase por todos los nodos exactamente una vez y regrese al inicio
