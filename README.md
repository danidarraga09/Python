# Resumen del código

1. **Crea un grafo** con 4 nodos y 6 aristas (todos conectados con todos)
2. **Verifica si es conexo** — si se puede llegar de cualquier nodo a cualquier otro
3. **Encuentra las componentes conexas** — grupos de nodos conectados entre sí
4. **Calcula el diámetro** — la distancia más larga entre dos nodos cualquiera
5. **Calcula el radio** — la distancia más corta desde el nodo más céntrico
6. **Encuentra el centro** — los nodos con menor excentricidad
7. **Verifica si es euleriano** — si existe un circuito que recorra todas las aristas una sola vez
8. **Aplica Fleury** — intenta construir ese circuito euleriano de forma cautelosa
9. **Aplica Hierholzer** — intenta construir ese circuito euleriano de forma eficiente
10. **Busca un ciclo hamiltoniano** — un camino que pase por todos los nodos exactamente una vez y regrese al inicio
